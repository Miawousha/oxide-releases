# A quiet place to write the markdown you keep in git.

Oxide is a Mac app for writing in markdown. Formatting appears as you type while the file stays plain text. Documents read like a well-set book. And every change, yours or Claude’s, is a diff you review before it counts.

    Write, don’t format.

    You type markdown and formatting appears as you go. The line you’re on shows its raw syntax; leave it and it renders.

    Lists continue when you press Enter. [[ suggests the pages you already have. Paste an image and it lands in assets/, linked. Tables edit as a grid. And the file on disk is the plain text you typed, byte for byte.

    • Shortcuts⌘B, ⌘I, ⌘L for a link, ⌥⌘1–3 for headings. Every action is in ⌘K.
    • SavingAutomatic after half a second of quiet, written atomically. There is no Save dialog to forget.
    • Outside editsIf another tool changes the file under you, Oxide asks: keep mine, take disk, or view the diff.

    Slow tools

    A good tool is one you stop noticing. It opens before you finish reaching for it, stays out of the way while you work, and never leaves you wondering what it did to your words.

    Most writing software fails the last test. It keeps a second copy of your text in a format of its own, and the file you think you own is an export. The day the software changes, so does your work.1

    What a slow tool keeps

    KeptWhere
    The wordsA plain .md file you can open anywhere
    Every revisionGit, one commit at a time
    How pages connectLinks in the text itself
    Write as if the tool will be gone in ten years. It probably will; the file will not.

    Why it matters now

    Agents read and write these files too. A format both a person and a model can read, with a history both can see, is the only kind of shared document that stays honest.

    1. The file is the source of truth. Everything else is a view of it.

    The three widths are Oxide’s own: 72, 80 and 95 characters. Pinch or ⌘= to zoom, and the column grows with the type.

    AI proposes. You dispose.

    Select a passage and ask for a rewrite. The answer streams in as a diff over your own words, and nothing changes until you accept it.

    Press ⌘J and Claude continues from your cursor as faint text you can take or ignore. The repo agent works at a larger scale: it answers with file-and-line citations, and its edits land in your working tree as ordinary changes, reviewed in the same git panel as yours.

    • EngineThe Claude Code CLI you already use. No API key, no second bill; Oxide never holds a token.
    • ControlOne switch turns AI off everywhere, another per repository. Everything else works without it.

    Git, for people who write.

    Every draft is on the record, and committing feels as light as saving.

    A status pill shows your branch and what changed. Changes open as word-level diffs tuned for prose, not line noise. Stage a file or a single passage, let AI draft the message from what you staged, commit, then sync: fetch, rebase, push.

    • HistoryEvery version of a page, across renames. Restoring one is a new change, never a rewrite.
    • ConflictsResolved in the app, one passage at a time. Abort puts every byte back.
    • AuthLeft to your system git. Oxide never sees a credential.

    Try it: stage, draft, commit, sync.

    Lean is a feature.

    Every dependency and every feature pays rent. What Oxide leaves out is part of the design.

    • AccountsNone. No sign-in, and no servers of its own.
    • TelemetryNone. The log is a plain-text file on your Mac.
    • PluginsNone, and no marketplace to manage.
    • NetworkOne call, the update check. Git, Claude Code and gh run as your own tools.

    First launch

    1. Open the .dmg and drag Oxide to Applications.
    2. Open Oxide. macOS stops it the first time.
    3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

    You do this once. Oxide is signed and every update is signature-checked before it installs, but Apple hasn’t notarized it yet, so macOS asks you to vouch for it.

    What it needs

    • macOS 14+On Apple Silicon. Intel Macs are not supported.
    • gitFor everything version control. Without it, Oxide is a reader and editor.
    • Claude CodeOptional. Installed and signed in, it powers the AI features.
    • ghOptional. Lets you browse and clone your GitHub repositories.
